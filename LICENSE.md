# Rights and distribution

This private draft does not grant an open-source license yet. The owners must
confirm the code license, author attribution and metadata publication scope
before changing the repository to public. No upstream license is replaced by
this file, and no MIT/BSD license is assumed for borrowed material.

UASpeech belongs to the University of Illinois. Obtain it through the
[official access process](https://speechtechnology.web.illinois.edu/uaspeech/).
The official conditions prohibit redistribution of audio/video outside the
recipient institution and restrict permitted uses. This repository contains no
source or reconstructed audio/video, participant images, actual waveforms,
model weights, or review databases. Local reconstruction does not transfer any
rights to redistribute those outputs.

Only source identifiers, corrected indices, processing recipes, audit statistics
and implementation code are included. The review screenshot hides licensed video
and illustrates waveform matching with explicitly labeled synthetic signals;
it is not evidence of a particular corpus alignment.

See [sources and verification](docs/SOURCES.md) for provenance and attribution.
